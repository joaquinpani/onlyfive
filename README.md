<h2>#1 WHAT IS THE GAME ABOUT??</h2>
<p>The game only five is heavily inspired in games like baldis basic, in a simple way only five is a video game made for virtual reality in which combining puzzles a super basic but memorable artistic design
and several zones and moments of suspense and terror the gameplay is heavily inspired in games like five nights at freddys security breach or bendy and the ink first person games in which you go advancing 
completing puzzles well only five tries to bring a part of the best of each world and in a frantic way but with a totally new mechanic you only have 5 minutes to complete the game!! but how is that possible? if 
at the beginning you will have to go solving the puzzles getting to know the characters and discovering how to advance but once you know all that follows the step of optimizing the time since you only have 5 minutes to complete the game since
if the alarm reaches 0 the game restarts and starts from 0</p>
